# Zahid Mir Studio — Enquiry API

## What it does
- Accepts website enquiries at `POST /api/leads`.
- Saves submissions to PostgreSQL when `DATABASE_URL` is set (SQLite is only a local-development fallback).
- Offers a protected `GET /api/leads` endpoint for the latest 100 enquiries.
- Sends an email notification when SMTP is configured. Database saving still works if SMTP is not configured.
- `GET /health` checks the database connection.

## Deploy with Render
1. In Render, choose **New → Blueprint** and connect this GitHub repository.
2. Review `render.yaml`. It defines a web service and PostgreSQL database. Render may change free-plan availability or require a paid database plan; check the price before confirming.
3. After deployment, open the API service and check `/health` returns `{"status":"ok","database":"connected"}`.
4. Copy the API service URL and set it in `product/index.html` as `API_BASE` (replace the example URL if Render assigns a different one).
5. In the API service environment, keep the generated `ADMIN_TOKEN` private. To view leads, send `Authorization: Bearer YOUR_ADMIN_TOKEN` to `GET /api/leads`. Never put this token in frontend code or GitHub.
6. To enable email notifications, set SMTP variables in Render's Environment settings. For Gmail, use `smtp.gmail.com`, port `587`, your full Gmail address as `SMTP_USER`, and a Google App Password as `SMTP_PASSWORD`. Never share your Gmail password or App Password in chat or commit it to GitHub. App Passwords require 2-Step Verification and may not be available for every account.
7. Test a real enquiry and verify it appears in the database / protected endpoint before advertising the form.

## Environment variables
- `DATABASE_URL`: Render PostgreSQL connection string (automatically mapped by Blueprint).
- `SITE_ORIGIN`: exact public website origin, currently the GitHub Pages origin.
- `ADMIN_TOKEN`: private token for reading enquiries; generated by Render.
- `LEAD_NOTIFY_EMAIL`: defaults to the studio email.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`: optional email delivery settings.

Do not add secrets to the frontend. A static GitHub Pages site cannot safely hold database credentials or SMTP passwords.
