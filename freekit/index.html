03 / The promise

Free should be
straightforward.

No fake download buttons. No pretending every premium feature is unlocked. No surprise claim that a tool is free when it requires payment.

01 / Privacy

Local when possible.

Image processing and text utilities run inside your browser. Your files are not sent to a FreeKit backend.

02 / Transparency

Know the limits.

We label free tiers and open-source software honestly. Self-hosting can still have hosting costs.

03 / Useful first

Task before hype.

Pick what you need to get done. The tool should be easy to find, quick to use and clear about the result.
